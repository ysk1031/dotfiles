# Design Plan Output Template

This template defines the structure for design plan output files (`design-<task>.md`).

## JSON → Markdown Field Mapping

Map the Phase 2 JSON output fields to Markdown sections as follows:

- `background` → `## 背景`
- `goal` → `## ゴール`
- `steps` array → `## 実装ステップ` (each step item → `### N. <step.title>` with `step.target`, `step.action`, `step.changes`, `step.reason`, `step.detail`)
- `testing` → `## テスト計画`
- `risks` array → `## リスクと考慮事項` (each → `- <risk.risk>: <risk.mitigation>`)
- `checklist` array → `## チェックリスト` (each → `- [ ] <item>`)

## Template

```markdown
# Plan: <task description>

> Generated by Claude Code design skill on <date>

## 背景

<Why this task is needed, context from research if available>

## ゴール

<What success looks like — specific, measurable outcomes>

## 実装ステップ

### 1. <step title>
- **対象ファイル**: `<path>` (create / modify)
- **変更内容**: <specific changes to make>
- **理由**: <why this change is needed>
- **詳細**:
  <detailed description, code snippets if helpful>

### 2. <step title>
...

## テスト計画

<How to verify the implementation works>

## リスクと考慮事項

<Potential issues, edge cases, breaking changes>

## チェックリスト

- [ ] Step 1: <brief description>
- [ ] Step 2: <brief description>
...
```
